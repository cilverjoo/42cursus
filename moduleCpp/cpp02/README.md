# 연산자 오버로딩

## 1. 연산자 오버로딩(재정의)은 무엇인가?

- 연산자 재정의를 하면 내가 정의한 클래스에서도 연산자를 쓸 수 있게 된다.
- C++에서는 아래의 연산자를 재정의 할 수 있다.
```
+, -, *, /, %, ^, &, |, ~, !, =, <, >, +=, -=, *=, /=, %=, |=, <<, >>, >>=, <<=, ==, != <=, >=, &&, ||, ++, --, ,, ->*, ->, ( ), [ ]
C++ 20 추가: <=>
```

## 2. 오버로딩 할 수 없는 연산자
```
::, . (멤버 변수/함수 접근), .*, ? 연산자는 오버로딩 할 수 없다.
=, (), [], -> 는 멤버 함수로만 구현할 수 있다.
```

## 3. 연산자 오버로딩 방법

```
std::ostream	&operator<<(std::ostream &os, const Fixed &fixed)
{
	return (os << fixed.toFloat());
}
```
<< 연산자의 앞에 오는 인자를 첫번째로, 뒤에 오는 인자를 두번째 파라미터로 넣어서 연산자 오버로딩 함수를 구현한다. output을 담당하는 ostream에 << 연산자를 통해 값을 전달할 수 있도록 이미 구현되어 있으므로 우리는 클래스에서 어떤 값을 뽑아서 넣어줄지만 구현해주면 된다. 중요한 것은 클래스 밖에다 선언하는 것!!


# Fixed Point Value

다음은 서브젝트에서 fixed point value 이해를 위해 읽기를 권장하는 기사의 요약본이다.

```
동일하게 보이는 부동 소수점 숫자가 반드시 C의 "=="테스트를 충족하지 않는다는 것을 종종 발견합니다. 새로운 프로그래머는 일반적으로 이러한 이유로 부동 소수점 수에 ==를 사용하지 않도록 배웁니다. 때때로 우리는 부동 소수점을 사용하여 구현 될 때 겉보기에 무작위로 보이거나 실망스럽게 부정확 한 결과를 생성하는 수학적으로 건전한 공식과 같은 다른 예외적 인 경우에 직면합니다.

실제로 부동 소수점 숫자에 대해 반 직관적 인 것이 많으며 프로그램에서 이를 생산적으로 사용하려면 한두 가지를 아는 것이 도움이됩니다.
```

```
"Accuracy" refers to how close a measurement is to the true value, whereas "precision" has to do with how much information you have about a quantity, how uniquely you have it pinned down.
```

```
integers lack precision. Dividing both 5 and 4 by 2, for instance, will both yield 2. Integers are unable to keep track of the fractional part, so the information that I had a slightly bigger number than 4 (namely, 5) is lost in the process.
```

```
먼저 equal이라는 성가신 문제를 해결해 봅시다. 왜 두 개의 수레가 같은지 알기가 그렇게 어려울까요? == 연산자는 실제로 두 개의 부동 소수점이 정확히 같은지 알려줍니다 (즉, 비트에 대해 일치). 그러나 여러분은 이러한 비트 중 일부가 어쨌든 부정확 할 수 있을 때 비트를 비교하는 것이 별로 의미가 없다는 데 동의 할 것입니다. 이것이 float의 정확도가 제한된 상황입니다. 결과는 한정된 단어에 맞게 반올림 되어야 하며 CPU 및 / 또는 소프트웨어가 예상대로 반올림되지 않으면 equality 테스트가 실패 할 수 있습니다.

그래서 equal은 무엇을 의미할까요? 일반적으로 "충분히 가까움"을 의미할 것입니다. 이러한 정신에서 프로그래머는 일반적으로 작은 거리를 "충분히 가까움"으로 정의하고 두 숫자가 그렇게 가까운지 확인하여 equality를 테스트하는 방법을 배웁니다. 다음과 같이 진행됩니다.

#define EPSILON 1.0e-7 
#define flt_equals(a, b) (fabs((a)-(b)) < EPSILON)
```

복잡하니까 간단히 말해보자면 고정소숫점은 10진수 수를 2진수로 바꾸는 일반적인 방법 그대로 수를 표현하는, 컴퓨터에서 사용하는 방식이다.

예를 들면 7.625라는 실수가 있다고 치자. 2진수로 변환하면 111.101이 될 것이다. 이걸 이렇게 저장한다.

```
     0 | 0000111 | 10100000
부호비트 | 정수부    | 소수부
```

맨 앞 1자리는 부호 비트 (Sign Bit) 라고 해서 0이면 양수, 1이면 음수라는 뜻이다. 나머지 비트들은 소수점을 기준으로 정수부랑 소수부를 표현하는 비트로 각각 나누게 되는데, 소수점의 위치는 미리 정해둔다.

소수부의 경우 앞에서부터 채우며 남는 뒷자리는 다 0으로 채운다. 이러한 고정소수점 방식은 구현하기 편리하지만 사용하는 비트 수 대비 표현 가능한 수의 범위 또는 정밀도가 낮기 때문에 실수를 다룰 필요가 있는 범용 시스템에서는 거의 안 쓰이고, 높은 정밀도가 필요없는 소규모 시스템에서는 간혹 쓰이기도 한다고 한다.
