## module cpp 03
- 클래스 상속
- 가상 소멸자 : 상속받는 클래스가 존재하는 경우 가상 소멸자를 사용하는것이 중요하다. 잘못하다간 메모리가 해제되지 않는 현상이 발생
- 가상 상속 : 말 그대로 가상으로 상속해준다는 의미. 
가상 상속을 이용하면 과다한 메모리 사용, 누수 등을 예방하고 base class가 다중/중복 상속되지 않아 효율적으로 함수 및 메모리 관리 가능
- 가상 상속 (cpp03 내의 README 참고)

## module cpp 04
- 가상함수 : 파생 클래스에서 재정의할 것으로 기대하는 멤버 함수
- 순수 가상함수 : 함수의 정의가 이뤄지지 않고 함수만 선언한 것
- 추상 클래스 : 클래스 안에 선언된 순수 가상함수가 있는 클래스를 지칭
- 인터페이스 : 특정 기능을 구현할 것을 약속한 추상 형식으로,멤버 필드나 구체적으로 구현한 메서드를 갖지 않고 특정 기능을 약속한 메서드만 갖는다.
- 클래스 상호 참조

## module cpp 05
- 예외 클래스 : public으로 std::exception을 상속한 예외 클래스를 만들어 적절한 에러메시지를 반환해야 한다.
- exception 객체를 발생시키거나 기초 클래스로 사용할 수 있음
- exception 클래스는 what()이라는 하나의 가상 멤버 함수가 주어지는데 이 what()을 오버라이딩하여 재정의한 문자열을 리턴하게 해 주면 된다.

## module cpp 06
- static_cast : 정적 캐스트, float, int와 같이 원래 정의되어 있는 형변환을 할 때 사용한다.
- dynamic_cast : 상속관계에서의 안전한 형변환 지원
- reinterpret_cast : 포인터/참조와 관련된 형변환만 지원. serialize를 할 때 사용 가능하다.
- const_cast : const 성질을 제거하고 싶을 때 사용, 메모리 구조가 다른 컴퓨터에서 const_cast를 사용했을 경우 에러가 발생할 수 있다.
