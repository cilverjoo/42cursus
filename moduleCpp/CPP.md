* 인스턴스(instance) : 객체지향 프로그래밍 환경에서 모든것을 다 객체로 표현하고 객체의 형식을 갖는 변수를 인스턴스라고 한다. 예를 들어, string strdata; 에서 strdata는 string 자료형에 대한 인스턴스이다.

* auto : 컴파일러가 자동으로 형식을 규정하는 자료형. 초깃값의 형식에 맞춰 선언하는 인스턴스의 형식이 자동으로 결정된다.

    [기본적인 변수 선언 및 정의]
    int a = 10;
    int a(10);
    int b(a);
    
    [auto의 선언]
    auto a = 10;
    auto b(a);
    
* new와 delete
    - c에서 다르게 c++에서는 new와 delete연산자를 활용하여 메모리를 관리한다. new와 deletesms c++에서 객체를 동적할당하고 해제하는 연산자이다. malloc과 비교했을 때 가장 큰 차이점은 "메모리 크기를 정하지 않는다"는 점이다. 단, 배열 형태로 동적 생성한 것은 반드시 배열 형태를 통해 삭제해야 한다.

       int *pNewData = new int[10];
       delete pNewData[];

- new 연산자는 객체의 생성자를 호출하고, delete 연산자는 객체의 소멸자를 호출한다.


* 참조자(Reference)
    - c에 없는 형식으로 포인터와 비슷하다. 그러나 **겉으로 드러나는 모습은 전혀 포인터 같지 않다**.
    - 또한 선언과 동시에 반드시 초기화해야 한다. (애초에 원래 변수가 없는 참조자란 있을 수가 없다!!)
    - 상수에는 포인터를 선언할 수 없는 것처럼 참조도 선언할 수 없다.
    
        [불가능한 경우]
        int *pData = &3;
        int &rData = 3;
        int &rData;
        
        [참조자의 사용법]
        int &ref = nData;
        ref = 20; //참조자의 값을 변경하면 원본도 변경된다!
        
        int *pnData = &nData;
        *pnData = 30;
        cout << nData << endl;    //결과 : 30

    - **덩치 큰 자료는 값이 아니라 '주소'를 전달하는 것이 효율적이다.**


* r-value 참조

    int &&rdata = 3;
    
    - 연산의 임시결과는 연산에 활용된 직후 소멸되는 r-value이다.
    - r-value 참조자라는 것은 이제 곧 사라질 대상에 대해 참조자를 부여할 수 있다는 것이다.

#### 디폴트 매개변수
- 매개변수의 디폴트값을 선언한 함수는 호출자 코드에서 실인수를 생략한 채 호출할 수 있다.
- c++에서는 호출자의 코드만 보고 함수의 원형을 확정해서는 안 된다!!

<pre>
<code>
int TestFunc(int nParam = 10)
{
    return nParam;
}

int _tmain(int ac, _TCHAR *av[])
{
    //호출자가 실인수를 기술하지 않았으므로 디폴트 값을 적용한다.
    std::cout << TestFunc() << std::endl;
    
    //호출자가 실인수를 확정했으므로 디폴트값을 무시한다.
    std::cout << TestFunc(20) << std::endl;
    
    return 0;
}
</code>
</pre>

- 디폴트 매개변수를 사용할 때 규칙

    1. 피호출자 함수 매개변수의 디폴트 값은 반드시 오른쪽 매개변수부터 기술해야 한다.
    2. 매개변수가 여러 개일 때 왼쪽 첫 번째 매개변수의 디폴트 값을 기술하려면 나머지 오른쪽 '모든' 매개변수에 대한 디폴트값을 기술해야 한다.
        (절대 중간에 뺴 먹으면 안 된다!!)
    3. 호출자 함수가 피호출자 함수 매개변수의 실인수를 기술하면 이는 왼쪽부터 짝을 맞추어 적용되며, 짝이 맞지 않는 매개변수는 디폴트 값을 적용한다.


#### 함수 다중 정의(Overloading)
- c++에서는 매개변수 구성이 달라지거나 어떤 식으로든 함수 원형이 달라지면 이름이 같더라도 다른 함수가 된다.
- 오버로딩한 함수를 사용하면 호출되는 함수가 컴파일러에 의해 자동으로 결정된다.
- 다중 정의에 영향을 주는 것은 **매개변수** 뿐이므로 그 외의 요소를 통해 오버로딩을 시도해서는 안 된다.


#### 햠수 템플릿
- c++에서는 함수 다중 정의보다는 '함수 템플릿'을 사용하는 것이 권장된다.

<pre>
<code>
    template <typename T>
    T TestFunc(T a)
    {
        std::cout << "매개변수 a : " << a << std::endl;
        return a;
    }
</code>
</pre>

- Template T의 형태를 int로 확정하고 싶다면 std::cout << TestFunc<int>(10) << std::endl; 와 같은 식으로 사용할 수 있다.
- typename T는 자료형을 의미한다.
- 호출자가 어떤 실인수로 TestFunc() 함수를 호출하는가에 따라 자동으로 다중 정의가 이루어진다.
